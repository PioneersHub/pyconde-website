{# Edition context band ──────────────────── One band per page for content belonging to a specific edition. Three states: - current edition (archive_year empty) → nothing - featured edition → "latest edition" band - any other past edition → "Archive" band The featured edition is the newest completed one, named in databags/site_state.yaml → featured_edition.year. It lives at the same permanent /archive/{year}/ URLs as every other past edition; only the framing differs, for as long as it is still being promoted. `kind` picks the sentence: talk | talks | speaker | speakers | track | tracks | edition. Unknown kinds fall back to a generic line. The archive copy stays here rather than in YAML on purpose: it is boilerplate that never changes per cycle. Only the featured-state copy — which does change every cycle — lives in the databag. Usage: {% from "macros/edition-context.html" import edition_notice %} {{ edition_notice(archive_year, 'talk') }} #} {#- `linked=false` suppresses the "Explore the {year} edition" CTA. Pass it from the edition landing page itself, where the link would point at the page you are already reading. It is a parameter rather than a check on `this.url_path` because an imported macro has no template context. -#} {% macro edition_notice(archive_year, kind='page', linked=true) %} {%- set fe = (bag('site_state') or {}).get('featured_edition') or {} -%} {%- set fy = (fe.get('year') or '')|string -%} {%- set year = archive_year|string -%} {%- if not year -%} {%- elif year == fy -%}
{{ fe.get('badge') or 'Latest edition' }} {%- if fe.get('note') %} — {{ fe['note'] }}{% endif %} {%- if linked %} Explore the {{ year }} edition. {%- endif %}
{%- else -%}
Archive — {%- if kind == 'talk' %} this talk is from the {{ year }} edition. See the current programme for the upcoming conference. {%- elif kind == 'talks' %} talks of the {{ year }} edition. {%- elif kind == 'speaker' %} speaker profile from the {{ year }} edition. {%- elif kind == 'speakers' %} speakers of the {{ year }} edition. {%- elif kind == 'track' or kind == 'tracks' %} tracks of the {{ year }} edition. {%- elif kind == 'edition' %} this page documents the {{ year }} edition of PyCon DE & PyData. See the current edition for the upcoming conference. {%- else %} content from the {{ year }} edition. {%- endif %}
{%- endif -%} {% endmacro %}
